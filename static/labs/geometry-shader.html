OpenGL · Geometry Shader Lab

看清 Geometry Shader 的真正变化：它不是“再处理一次顶点”，而是一次接收一个完整图元，再决定要输出哪些新图元。
WebGL2 没有 Geometry Shader stage。这个页面用 Canvas 把桌面 OpenGL 的 gl_in[] / EmitVertex() / EndPrimitive() 语义逐步画出来；不是把 CPU 模拟冒充成 WebGL Geometry Shader。

实验

A · 一个点生成一座房子

输入只有 1 个 point。Geometry Shader 围绕 gl_in[0].gl_Position 连续调用 5 次 EmitVertex()，输出一个 triangle_strip。

B · 整个三角形沿面法线移动

一次拿到三个顶点后，先算 face normal = normalize(cross(a,b))，再给三个顶点加同一个位移。三角形不会被拉扯，而是整块移动。

C · 从三角形生成法线线段

对每个输入顶点输出“起点 + 终点”两个顶点，再 EndPrimitive()，所以 3 个输入顶点会生成 3 条线，共 6 次 EmitVertex()。
