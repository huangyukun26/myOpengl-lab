① 官方参数 / 专注观察模式

单独选定行或列后，滑块只覆盖所选维度；未选中的维度仍保留官方梯度。调试通道显示所选分量，不改变 BRDF 核心公式。AO 只乘近似 Ambient，不修改直接光照。

② 片元着色器的计算次序

输入 N,V,LWorldPos · Normal · camPos · 4 灯
→
H, D, G, F半程向量 · GGX · Smith · Fresnel
→
BRDFkD·albedo/π + DGF/4NdotVNdotL
→
LoΣ BRDF × radiance × NdotL
ambient = vec3(0.03) * albedo * ao;
color = ambient + Lo;
color = color / (color + vec3(1.0)); // Reinhard
color = pow(color, vec3(1.0/2.2));   // Gamma

③ 看效果时应该重点比较什么？

D 通道：观察法线朝向 H 的密度随粗糙度变化。D 是密度，可以超过 1，预览作了显示映射。

G 通道：将相机旋转到掠射角，微平面可见性下降；注意它不是 SSAO 或大场景的投射阴影。

F 通道：金属与非金属的 F0 差异明显；掠射角反射份额增加。

Diffuse / Specular：全金属几乎无漫反射，粗糙度改变高光分布。这里故意只做官方 直接光照；真实金属还需要后续 IBL 环境反射。
