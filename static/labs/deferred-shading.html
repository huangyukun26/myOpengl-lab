Deferred Shading Lab

第一遍真实写入 Position / Normal / Albedo+Spec G-Buffer；第二遍只画 Fullscreen Quad，再从 G-Buffer 读取表面信息计算多光源。

这次真正被“延迟”的是什么

Geometry Pass
→ Position
→ Normal
→ Albedo / Specular
→ 先存进 G-Buffer

Lighting Pass
→ Fullscreen Quad
→ 每个屏幕像素查 G-Buffer
→ 再遍历 Lights
→ Final Color

观察方法

先依次切 Position、Normal、Albedo，看第一遍并没有输出最终光照，而是在记录“这个像素对应的表面是什么”。再切 Final 并增加 Lights：几何没有重新画一遍，变化发生在第二遍 Lighting Pass。
