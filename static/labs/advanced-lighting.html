Phong：比较 V 和 R

当 V 与 R 的夹角超过 90° 时，dot(V,R) 变成负数，max(...,0) 会把镜面项直接截成 0。低 shininess 时高光本来应该很宽，因此这个截断更容易被看见。

R = reflect(-L, N) spec = pow(max(dot(V, R), 0.0), shininess)

Blinn-Phong：比较 N 和 H

H 是 L 与 V 的中间方向。可见表面上 H 与 N 的夹角变化更平滑，因此高光边缘通常不会出现 Phong 那种突兀截断。

H = normalize(L + V) spec = pow(max(dot(N, H), 0.0), shininess)
