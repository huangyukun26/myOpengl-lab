实验

A · 一次画一个，还是一次画很多个

画面尽量保持一样，只改变 CPU 发出的绘制方式。普通方式循环调用 drawArrays；实例化方式只调用一次 drawArraysInstanced。

B · 每个实例都有自己的 gl_InstanceID

用 gl_InstanceID 控制缩放

同一份 quad、同一个 Draw Call。Vertex Shader 里 gl_InstanceID 会从 0 开始随实例递增。

C · Attribute 到底多久换一次

颜色是 instanced attribute。把 divisor 从 1 改成 2 / 4，可以直接看到同一份 instance attribute 被几个实例共享。

D · 小行星带：mat4 作为实例属性

旋转观察场景

所有岩石共享一份低模 Mesh；每颗岩石只有自己的 Model Matrix。Matrix 被拆成 4 个 attribute location，并全部设置 divisor = 1。
