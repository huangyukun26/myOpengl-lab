PBR Lighting · LearnOpenGL Forward Renderer / 完整数据流

这节的完整 Pipeline 指当前官方直接光照示例：CPU 绘制球 → 顶点着色器 → 片元 BRDF → 4 灯的 Lo → 常量 ambient → Tone Mapping → Gamma → 屏幕。没有 Deferred/G-Buffer，也没有 IBL。

① CPU / Material49 spheres · 行 metallic · 列 roughness · albedo · AO
→
② Vertex ShaderModel 平移/缩放 · WorldPos · Normal · Clip Position
→
③ Fragment BRDFV、L、H → D、G、F → diffuse + specular
→
④ Direct LightingLo += BRDF × radiance × max(N·L,0) × 4 灯
→
⑤ Displayambient×AO + Lo → Reinhard → γ=2.2 → FragColor
D / GGX分布密度。roughness→α=r²；根据 N·H 查询法线方向。Lab 的 D 预览做了 d/(1+d) 显示映射。
G / SmithMasking × Shadowing。用 N·V 和 N·L 分别计算微结构双向可见性，乘积为近似。
F / FresnelF0=mix(0.04,albedo,metallic)，根据 H·V 调整 RGB 镜面反射份额；metallic=1 时 kD=0。

对照 PBR Lighting Lab 的 Final / D / G / F / Diffuse / Specular 标签逐项核查。原教程：LearnOpenGL PBR Lighting。
