完整图元进入 Geometry Shader，再生成新的图元

Primitive Assembly 已经把顶点组成 point / line / triangle。Geometry Shader 一次处理一个完整图元，可以输出 0 个、1 个或多个新图元，再交给 Rasterization。

重点位置：Primitive Assembly → Geometry Shader → Rasterization
